# 🎭 Manual to Playwright Automation Roadmap

A structured learning journey focused on Software Testing fundamentals, JavaScript/TypeScript, Playwright automation, professional framework development, API testing, CI/CD, and real-world QA projects.

> The roadmap is designed to progress from **testing fundamentals → Playwright automation → framework development → CI/CD → project implementation → interview readiness.**
